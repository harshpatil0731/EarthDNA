# EarthDNA

EarthDNA is a software-based ecosystem intelligence platform that studies wildfire risk across Uttarakhand, Southern California, and Southeastern Australia. It combines satellite, weather, and historical environmental data with explainable machine learning and evidence-grounded recommendations.

The approved project specification is in `EarthDNA_README new.md`; the implementation schedule and GitHub strategy are in `EarthDNA_Phase_Plan new.md`.
